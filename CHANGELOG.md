## v1.0.0 - 2026-03-01

### Initial stable release (Filament 4.x)

A Filament form field powered by MUI X Date Pickers and React.

#### Highlights

- Material UI date picker with full Livewire two-way binding
- Desktop, mobile, and static picker variants
- Min/max date constraints with automatic validation rules
- 40+ built-in locale translations
- Dark mode and primary color support
- Clearable input, Today button, landscape/portrait orientations

#### Compatibility

- Filament 4.x
- Laravel 11.x, 12.x
- PHP 8.2+
